# SEO Toolkit

My working toolkit for SEO audits and optimization projects — checklists, templates and process notes.

## My Audit Workflow
Research → Audit → Identify Problems → Prioritize → Recommend Solutions → Implementation → Verification → Reporting

## Audit Coverage
- Crawling & indexing, sitemap, robots.txt
- Canonicals, redirects, broken links
- Duplicate content & meta, missing titles/descriptions, H1 structure
- Image alt text & schema markup
- Core Web Vitals / PageSpeed
- Internal linking & keyword mapping
- Competitor analysis & content optimization
- Google Search Console review & reporting

## Tools
Ahrefs • Google Search Console • Google Analytics • Google Tag Manager • Screaming Frog methodology
